HTML & CSS Mini Project

I built three pages:

* Dashboard
* Sign In
* Sign Up

I used HTML and CSS to make the pages look like the given designs and work on both desktop and mobile.

I used

* HTML
* CSS
* Flexbox
* CSS Grid
* Media Queries

This project helped me practice making layouts with CSS, using Flexbox and Grid, and making a website responsive for different screen sizes. I also got more practice using Git and GitHub.
